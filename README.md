# SMS_Spam_Classifier
This project uses Python to create a machine learning model that categorizes SMS messages as spam or not. TF-IDF vectorization is used to analyze the dataset, which is obtained from the UCI Machine Learning Repository. A Multinomial Naive Bayes classifier is then trained to get a high level of accuracy. The application also contains optional Seaborn visualization, data preparation stages, and metrics for model evaluation such as accuracy, confusion matrix, and classification report. The whole code, together with all the instructions needed to download, prepare, train, and assess the model, is available in this repository.
